Krok 3: Umieść pliki na GitHubie 1. Zaloguj się na GitHub.com. 2. Kliknij przycisk New (lub ikonę plusa w prawym górnym rogu -> New repository). 3. Ustaw parametry: • Repository name: Wpisz dowolną nazwę (np. pobieralnia). • Public/Private: Musisz wybrać Public (darmowe strony GitHub Pages działają tylko na publicznych repozytoriach). 4. Kliknij Create repository. 5. Na nowej stronie kliknij link "uploading an existing file". 6. Przeciągnij i upuść całą zawartość swojego folderu (plik index.html oraz pliki do pobrania). 7. Kliknij zielony przycisk Commit changes na dole strony. Krok 4: Włącz stronę internetową (GitHub Pages) 1. W swoim repozytorium na GitHubie wejdź w zakładkę Settings (koło zębate na górnym pasku). 2. Z menu po lewej stronie wybierz Pages (w sekcji Code and automation). 3. W sekcji "Build and deployment" znajdź opcję Branch. 4. Zmień ustawienie z None na main (lub master) i kliknij Save. Gotowe! Po około 1-2 minutach odśwież stronę w ustawieniach. Na samej górze sekcji GitHub Pages pojawi się adres URL Twojej strony (np. https://github.io).
